# 全国教师招聘公告扩源 S0：范围与来源规范

> 阶段：S0
> 日期：2026-10-23
> 状态：方案/规范阶段，未修改业务代码
> 目标：为后续自动抓取全国教师招聘公告建立可审计的范围、来源、公告类型和验收口径。

## 1. S0 结论

全国扩源可以实施，但本项目不把“全国”解释为首期一次性覆盖所有地区，也不承诺全国公告零遗漏。

本阶段确定以下产品边界：

1. 只登记并抓取公开可访问的官方来源。
2. 省级来源不等于该省所有市县都已覆盖；市县来源需要单独登记。
3. 当前用户端继续以语文教师岗位为主；其他学科可以归档和统计，但不自动进入当前语文机会匹配。
4. “教师招聘”不自动等于“教师编制”。编制、备案制、员额、合同制、劳务派遣等按官方原文分别标记；原文未说明时标记为“未说明”，不推断。
5. 公告正文、岗位表、专业目录、补充说明、更正/延期/取消文件属于同一业务材料包时，应建立关联，但不能互相覆盖原文证据。
6. 未监测、未核实、抓取失败、解析失败、来源无新增和确认无在报公告必须区分，不能统一展示为“没有招聘”。
7. 任何进入正式用户机会列表的数据，必须经过证据审核和正式发布；抓取成功不等于可以展示。

这些边界承接当前 v7.1/v7.2 的既有规则：当前只开放语文学科、资格结论是公开信息下的初步预筛、主要推荐必须有官方来源并通过发布门槛、未覆盖地区显示“暂未收录”。

## 2. 公告范围

### 2.1 首期纳入

| 类型 | 处理方式 | 说明 |
|---|---|---|
| 教师公开招聘公告 | 纳入 | 以官方发布机构和正式正文为准 |
| 岗位表/招聘计划表 | 纳入 | 与对应公告建立材料包关系 |
| 专业目录、资格条件附件 | 纳入 | 作为资格判断证据，不单独伪装成招聘公告 |
| 补充公告、更正公告 | 纳入 | 关联原公告并生成新版本或变更记录 |
| 延期、取消、核减、岗位调整公告 | 纳入 | 优先级高于一般说明，影响在报状态和岗位数量 |
| 报名时间、报名入口、资格审查时间调整 | 纳入 | 进入公告版本和关键节点 |

### 2.2 首期不承诺自动处理

| 类型 | 处理方式 |
|---|---|
| 笔试成绩、面试名单、体检考察等后续流程公告 | 原文可归档，暂不作为首期岗位发现核心 |
| 需要登录、验证码、付费或绕过访问限制才能获取的内容 | 不自动抓取，转人工记录 |
| 只有图片扫描件且没有可用文本层的附件 | 保存原件并进入人工/OCR待处理，不伪装为已解析 |
| 非官方聚合网站、个人整理、培训机构转载 | 可作为遗漏线索，不能作为正式发布来源 |
| 学校自主招聘且不属于公开招聘口径的公告 | 单独标注来源类型，是否纳入由后续产品决策确定 |

### 2.3 用工类型口径

系统只保存官方原文明确表达的用工属性：

- 事业编制/纳入编制管理
- 备案制
- 员额/控制数/报备员额等地方口径
- 合同制/聘用制
- 劳务派遣/临聘
- 未说明
- 其他原文口径

不得因为公告标题包含“招聘教师”“公开招聘”就自动填为“事业编”。岗位类型不确定时，候选字段进入人工确认，正式载荷保留未知状态并展示官方依据。

## 3. 来源台账规范

### 3.1 来源登记单位

来源登记以“官方发布机构 + 具体栏目”为最小单位，不以省份作为唯一单位。建议分层登记：

1. 省级教育主管部门或省级人社部门公告栏目。
2. 地市教育局、人社局或政府事业单位招聘栏目。
3. 区县教育局、政府门户或人事考试栏目。
4. 依法承担招聘发布职责的学校或教育集团官方栏目，需单独确认权威性。
5. 官方附件域名或对象存储域名，作为来源允许域名的关联项。

### 3.2 来源台账字段

后续来源登记至少需要以下字段：

| 字段 | 要求 |
|---|---|
| sourceKey | 稳定、不可因栏目标题变化而随意变更 |
| publisher | 官方发布机构全称 |
| administrativeRegion | 省、市、区县代码和名称分开保存 |
| authorityLevel | 省级/市级/区县级/学校等 |
| officialEntryUrl | 官方入口页 |
| listUrls | 已核验的栏目列表页和分页入口 |
| allowedHosts | 正文与附件允许访问的官方域名 |
| contentScope | 教师公开招聘/事业单位教师岗/其他 |
| adapterKey | 适配器或共享模板键 |
| pollPolicy | 检查频率、重点招聘期策略 |
| accessNotes | 是否需要特殊请求头、分页规则、附件跳转规则 |
| sourceStatus | 待核实/试运行/正常/异常/暂停 |
| lastCheckedAt | 最近一次有效检查时间 |
| lastSuccessAt | 最近一次成功发现或有效读取时间 |
| failReason | 最近失败原因，不能只写“失败” |
| owner | 维护人或维护角色 |
| sampleRefs | 真实黄金样本和回放样本引用 |
| coverageNote | 覆盖栏目、未覆盖范围和边界说明 |
| verifiedAt | 最近人工核验时间 |

### 3.3 来源状态定义

- **待核实**：官方域名或栏目尚未完成人工确认。
- **试运行**：已能抓取，但未完成完整正文、附件、字段和发布闭环。
- **正常监测**：完成真实样本验收，并有可持续检查记录。
- **异常**：连续失败、结构变化、权限变化或附件解析异常，需要处理。
- **暂停**：明确暂停自动检查，保留原因和最后成功时间。

“正常监测”必须有来源级检查记录，不能仅凭代码中存在适配器判断。

## 4. 公告材料包和版本口径

同一招聘批次下，正文、岗位表、专业目录、报名说明和更正文件构成材料包。材料包需要保存：

- 每份文件的原始 URL、来源、抓取时间、内容指纹和存储位置。
- 文件与公告的关系：正文、岗位表、专业目录、补充、更正、延期、取消等。
- 文件之间的证据定位：网页段落、PDF 页码、表格工作表/行列。
- 材料变化前后的版本链，不覆盖旧原件。

关联规则：

1. 官方明确说明“更正/补充/延期/取消”的文件，建立明确关系。
2. 只有内容相似但没有官方关系说明的文件，只标记为疑似关联，进入人工确认。
3. 同一公告新快照形成新版本，不新建无意义的重复公告。
4. 跨站转载不直接当作新招聘；保留转载证据，并通过发布机构、批次、日期、岗位标识和内容指纹产生重复候选。
5. 附件晚到、附件内容变化或更正关系变化时，重新触发材料包复核。

## 5. 岗位与学科范围

### 5.1 语文优先

当前产品的公共机会匹配继续只面向语文教师。抓取层可以完整保存公告中的其他学科，但后续处理应分为：

- 语文岗位：进入当前字段抽取、审核、发布和匹配链路。
- 其他学科岗位：可归档或统计，默认不进入语文机会列表。
- 无法确定学科的岗位：保留原文并进入人工确认，不猜测。

“语文”不能仅依靠岗位标题中的单个词判断。需要结合岗位表学科列、专业方向、招聘计划和公告上下文；同一岗位表中的多学科行必须逐行处理。

### 5.2 地区口径

岗位地区、发布机构地区、招聘单位地区和学校实际所在地分开记录。区县岗位不能只继承市级代码；如果原文无法确定学校或招聘单位所在区县，标记为未知并保留原文。

用户端覆盖口径必须能回答：

- 当前监测了哪个省、哪个市、哪个区县。
- 监测的是哪一个官方栏目。
- 最近一次有效检查是什么时候。
- 当前是否存在已经审核发布的语文岗位。
- 哪些地区尚未收录。

未收录必须显示为“暂未收录”，不能写成“当地没有招聘”。

## 6. 来源优先级和首批筛选规则

### 6.1 来源优先级

优先级从高到低：

1. 发布招聘决定或岗位计划的政府教育/人社官方栏目。
2. 官方政府门户中明确归属教育或人社机构的招聘栏目。
3. 官方人事考试或事业单位招聘平台中可核验发布机构的公告。
4. 学校或教育集团官方招聘栏目，需明确其招聘性质和权威关系。
5. 非官方聚合或转载，仅作为发现线索，不作为正式事实源。

### 6.2 首批扩源筛选条件

S4/S5 选择来源时，优先满足：

- 有稳定且公开的栏目入口。
- 不要求登录、验证码或绕过限制。
- 能取得正文和至少一种岗位材料。
- 公告量和用户需求具有代表性。
- 页面模板、分页方式、附件格式具有差异，可覆盖技术样本。
- 发布机构、地区和更新时间可核验。
- 有历史公告可作为回放样本。

首批来源不按“省份数量”凑数，建议同时覆盖省级、市级和区县级来源，以验证省级来源不能替代市县覆盖的事实。

## 7. 独立对账与验收口径

### 7.1 对账原则

系统召回率不能用系统自己发现的公告作分母。每个试点来源必须在明确时间窗口内建立独立的官方栏目对账清单：

1. 由人工按官方栏目分页、日期和公告类型建立目标清单。
2. 排除不属于教师招聘范围的公告，并记录排除理由。
3. 由系统与清单按规范化 URL、标题、发布时间和内容指纹匹配。
4. 对未发现项目标记原因：未发现、访问失败、解析失败、错误分类、重复关联、待人工。
5. 更正、延期、取消公告单独检查，不能只对账初始招聘公告。

### 7.2 建议指标

以下是后续开发的建议验收指标，当前不是实测结果：

- 来源有效检查率：有效完成检查次数 / 应执行检查次数。
- 公告发现召回率：系统发现的目标公告 / 独立对账清单目标公告。
- 材料完整率：正文和应有附件均可读取的公告 / 对账目标公告。
- 高影响字段证据覆盖率：带官方定位证据的高影响字段 / 应审核的高影响字段。
- 字段准确率与遗漏率：必须使用独立人工标注样本，不能把证据覆盖率当准确率。
- 发现时延：官方可观测发布时间到系统发现时间；只有日期时不虚构分钟级精度。
- 审核积压：待审核候选数量、最老待审时间和每日审核耗时。
- 重复率：重复抓取未生成重复快照/重复公告的比例。

建议目标需要在 S4 用真实样本校准。阶段性目标可以设为：来源有效检查率不低于 98%，独立对账的公告召回率不低于 95%；这些是试点目标，不是全国承诺。
