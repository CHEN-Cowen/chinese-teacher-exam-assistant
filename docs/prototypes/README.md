## Coding 工具读取顺序

1. 先读仓库根目录的 `PRD.md`；
2. 再打开本目录对应 HTML，理解信息层级与状态变化；
3. 回到现有 `src/app/globals.css` 和 `src/components/ui/` 复用真实设计系统；
4. 对照 PRD 验收清单实现，不依据原型中的示意岗位、机构、日期或数量创建生产数据。

## 原型与需求冲突时

按以下优先级处理：

1. 用户最新明确要求；
2. 当前 PRD；
3. 当前实现与测试记录；
4. 原型 HTML；
5. 更早的讨论稿。

原型中的颜色、阴影和图标仅用于表达层级。路由、保存位置、审核约束、数据来源和错误处理必须以 PRD 为准。
