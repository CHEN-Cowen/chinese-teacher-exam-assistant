# WorkBuddy 应有字段清单（Field Catalog）

> 本文定义 WorkBuddy 抽取/审核必须覆盖的字段口径。
> 每字段标注：范围（announcement / job / 两者视原文）、高影响、必需、允许未知、证据要求、标准化边界。

## 图例

- **范围**：`A`=公告公共、`J`=岗位、`A/J`=视原文结构（归属判定见 spec §1.3）
- **高影响**：`高`=无证据锚点不得过审（与 `domain.ts` `HIGH_IMPACT_FIELDS` 对齐）
- **必需**：`是`=该字段在发布载荷中必须存在（可为 unknown，但不可缺失键）
- **允许未知**：`是`=原文未写时置 `unknown`，不算不符合

## 补充规则

1. **报名时间、材料、入口必须绑定到明确批次**：字段 22–26 属于同一批次（`batch`），
   不得出现“入口无批次”“材料无截止”的悬空值；批次由字段 6 定义。
2. **“师范”保留**：专业字段标准化时不得剥离“（师范）”等限定词，它影响资格判定。
3. **年龄基准日/例外**是独立字段：不得并入年龄字段文本；基准日缺失 = `unknown` 而非推断。
4. **跨岗位混值防护**：凡范围=J 的字段，抽取时必须与具体岗位行绑定；
   禁止用首个数据行的值填充其它岗位。
